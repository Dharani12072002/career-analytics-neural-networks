# Career Analytics Using Neural Networks

## Problem Statements
1. Job Role Analyzer using Neural Networks (Classification)
2. Career Transition Difficulty Index Prediction (Regression)

## Dataset
- Career Prediction Dataset (Kaggle)

## Models Used
- Feedforward Neural Networks
- ReLU activation in hidden layers
- Softmax for classification output
- Linear activation for regression output

## Evaluation Metrics
### Classification
- Accuracy
- Precision
- Recall
- Confusion Matrix

### Regression
- MAE
- MSE
- RMSE
- Error Distribution Plot
